# medievail-battle

> **Projet collectif.** Ce projet est une œuvre collective réalisée en équipe dans le cadre de la formation STI3A à l'INSA Centre-Val de Loire. **Tous les contributeurs conservent leurs droits sur leurs contributions** ; l'historique Git complet, avec la paternité et les dates d'origine de chaque commit, est préservé. La liste des auteurs et les dépôts de référence figurent dans [AUTHORS.md](AUTHORS.md). Ce dépôt est un miroir maintenu par [@aziz3r](https://github.com/aziz3r) ; seuls les fichiers générés à l'exécution (`venv/`, `__pycache__/`, `battle_*.txt`) ont été retirés de l'historique.
